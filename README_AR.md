# إنجاز التسميع اليومي — الإصدار المطور التجريبي

هذه حزمة ملفات كاملة **للرفع على فرع `v2-development` فقط**. لا تعدّل `new-design` ولا إعدادات GitHub Pages.

## الميزات
- واجهة واحدة ومحرك Canvas واحد لقالبين.
- القالب الأول بنفس المجموعتين والطلاب الحاليين.
- قالب ثانٍ عمودي لـ12 اسمًا، مع تغيير الأسماء من واجهة البرنامج وحفظها على هذا الجهاز.
- بيانات التسميع منفصلة بين القالبين، ومفصولة أيضًا بالتاريخ.
- اختيار 100% و50% وX و0% وغائب ومحروم؛ تصدير PNG، مشاركة وطباعة.
- بيانات القالب الجديد تحفظ محليًا في المتصفح وليست متزامنة بين الأجهزة.

## تركيب آمن
1. ارفع **محتويات الحزمة** إلى الفرع `v2-development` فقط (واستبدل الملفات المطابقة).
2. **لا** تغيّر فرع النشر الحالي `new-design`.
3. جرّب عبر تشغيل `index.html` في VS Code باستخدام Live Server أو على مستضيف اختبار مستقل. GitHub Pages لا يعرض الفرع الثاني عبر رابط الموقع نفسه دون تغيير إعدادات النشر.
4. بعد اختبار كلا القالبين وتصدير الصور، يمكن دمج النسخة الجديدة لاحقًا.

## تعديل القوالب
`templates.js` لإعدادات القوالب والأسماء الافتراضية؛ `report.js` لمواضع الرسم. لتعديل الاسم الافتراضي في القالب الثاني غيّر دالة توليد الطلاب في `templates.js`.

## مهم
المصدر هنا مبني على نسخة محلية سابقة للمشروع (V2 fixed)، وليس سحبًا مباشرًا لآخر ملفات GitHub؛ لا ترفع الحزمة فوق الموقع المنشور. راجع توافقها مع آخر تعديلاتك قبل اعتمادها.
