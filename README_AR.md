# إنجاز التسميع اليومي V2

## تركيب الملفات
- `index.html` الواجهة الرئيسية.
- `style.css` تنسيق واجهة الإدخال.
- `students.js` المصدر الوحيد لأسماء الطلاب ومجموعاتهم وأسمائهم البديلة في Google Sheets.
- `app.js` استيراد البيانات والتعديل والحفظ المحلي والأزرار.
- `report.js` الرسم على Canvas والتصدير بنفس المعاينة.
- `assets/background.png` صورة الخلفية المرجعية الأصلية كما رفعها المستخدم؛ لا تُغيّر أبعادها دون مراجعة مواضع التقرير في report.js.

## النشر على GitHub
1. افتح فرع `new-design` في مستودع `fatima-hoffaz`.
2. ارفع الملفات الخمسة إلى جذر المستودع، والخلفية إلى مجلد `assets`.
3. لا ترفع ZIP نفسه بدل الملفات. احتفظ بفرع `main` كما هو.
4. اختبر النسخة محليًا أو انشر الفرع إلى رابط معاينة منفصل؛ GitHub Pages الرئيسي لا يتغير حتى يُدمج هذا الفرع.

## تعديل الأسماء
داخل `students.js` غيّر `name` أو `aliases` أو أضف كائن طالب. لا تغيّر `id` لطالب موجود حتى يبقى محفوظًا في السجل المحلي. أي اسم غير مُعرّف في `students.js` لا يدخل التصميم.

## حفظ البيانات
يُحفظ سجل كل تاريخ داخل `localStorage` في المتصفح والجهاز نفسه؛ لا يزامَن بين الأجهزة ولا يُرفع إلى GitHub. زر التفريغ يؤثر على التاريخ المحدد فقط.

## الرسم والتصدير
Canvas يعمل على 1620×971 مطابقًا للخلفية. المعاينة والصورة المصدّرة هما العنصر نفسه، حتى لا يظهر اختلاف في القصّ. خيار مشاركة PNG يستخدم Web Share API إن كان متاحًا، وإلا ينزّل الصورة. جودة التصدير الأصلية 1620×971.

## ملاحظات إدخال بيانات Sheets
الصق بيانات يوم واحد فقط. يستخدم المحرك أسماء الطلاب والأسماء البديلة لاكتشاف الصف. ينسخ السورة والتقييم ولا يستنتج نسب الإنجاز؛ اختر النسب بنفسك. عند «غائب» يدمج الخانات، وعند «مفصول» أو «محروم» يعرض `-`. كلمة «لم يسمع» تتحول X. الحقول غير المطابقة للطلاب لا تُضاف.

## الاختبار
جرّب على الأقل: طالب أنجز 100%، طالب أنجز 50%، طالب لم يُسمّع X، غائب، مفصول، وتاريخ آخر. افحص صورة PNG على الهاتف، خصوصًا ظهور الخلفية والكتابة العربية. لا تنشر `main` قبل نجاح الاختبارات.
